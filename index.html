          How this dashboard works

          1. Start guide — a ten-step walkthrough (recommended the first time).
          2. Load data — 28 days of hourly flow and pressure for 8 zones: weekday and weekend demand, weather, planned work (not always announced), hydrant use, sensor drift and hidden leaks.
          3. Train model — fits the ML model on days 1–21. The comparison panel shows, for days 22–28, how many leaks each method caught, how many false alerts it raised and how much leak water it saved — every method tuned to the same false-alert budget.
          4. Run live or +1 hour — advance the network. An incident opens after two consecutive abnormal hours.
          5. Select a flagged zone, read the Context tab, then acknowledge and either dispatch a crew or close with no action. The crew reports two hours later; leaks nobody catches are reported by customers.
          6. Try a scenario acts on the selected zone.

          The context check only uses what an operator would know: announced work, the day's weather, and whether pressure fits the flow.
