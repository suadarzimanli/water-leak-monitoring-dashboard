          How this dashboard works

          1. Start guide — a step-by-step walkthrough (recommended the first time).
          2. Generate Data — simulates 28 days of hourly flow and pressure for 8 zones, with daily demand peaks, weather, scheduled work, hydrant use, sensor drift and hidden leaks.
          3. Train Model — fits a leak model on days 1–21 and reports leaks caught and false alerts on days 22–28. Compare ML + context check, ML only and Rules only.
          4. Live simulation — one network hour per tick. An incident opens after two consecutive abnormal hours.
          5. Select a flagged zone, read the Context tab, then follow the workflow (Acknowledge, Work order, Dispatch, Close). After closing, the dashboard shows what the simulation really contained.

          The context check only uses what an operator would know: the published schedule, today's weather, and whether pressure fits the flow.
